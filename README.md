# WinBox Comment Patcher

Нативное macOS-приложение на Swift / AppKit, добавляющее отображение комментариев
Windows-1251 в MikroTik WinBox наряду с UTF-8.

## Для чего нужен патч

WinBox декодирует байты комментариев как UTF-8. Старые комментарии, записанные
в Windows-1251, могут отображаться с неправильными символами или `�`.
Патч добавляет декодирование исходных байтов до создания строки интерфейса.

## Требования для работы

| Требование | Значение |
| --- | --- |
| ОС | macOS 12 или новее |
| Процессор | Apple Silicon или Intel; патчер и встроенная библиотека universal |
| Целевое приложение | Исходная universal-сборка **WinBox 4.5.102000** |
| Доступ | Чтение приложения и запись в его родительскую папку |
| Состояние WinBox | Выбранное приложение должно быть закрыто |
| Диск | Поддержка атомарного обмена каталогов; место для временной подготовки и резервного архива |

Другая сборка, неизвестный изменённый исполняемый файл или повторное применение
текущего патча отклоняются. Версия патчера 1.3.0 предназначена для исходной WinBox 4.5.102000.
Для WinBox 4.4.102000 используйте патчер 1.2.0.
Совпадения одного номера версии недостаточно. Python, Xcode и интернет
при работе готового приложения не нужны.

Патчер и изменённый WinBox получают локальную подпись **ad-hoc**.
Developer ID и Apple notarization в текущую сборку не включены;
корпоративные политики macOS могут ограничивать запуск таких приложений.

## Использование

1. Скачайте `WinBox-Comment-Patcher-<версия>.zip` из раздела **Releases** и распакуйте.
2. Закройте выбранный WinBox.
3. Откройте **WinBox Comment Patcher.app**.
4. Нажмите **«Выбрать WinBox…»** и выберите установленное приложение.
5. Выберите режим кодировки и нажмите **«Применить патч»**.
6. После сообщения **«Готово»** запускайте WinBox по прежнему пути.

Чтобы вернуться к исходному WinBox, используйте резервный архив или исходную
дистрибуцию той же сборки.


## Область изменения и ограничения

- Перенаправляется декодирование роли комментария `CommentRole (0x104)`
  в `BaseTableModel::data` для arm64 и x86_64. Эту роль читают таблица
  и `WTableModel::getComment`.
- Общий UTF-8-декодер Qt и функции отправки конфигурации не изменяются.
  При чтении сохраняются исходные байты модели.
- В окне редактирования объекта перехватывается заполнение `TextView::refresh`
  для встроенного поля `Comment` (`SComment`). Windows-1251 преобразуется
  перед передачей текста в `TextWidget`; UTF-8 продолжает отображаться штатно.
  Остальные текстовые поля используют исходный обработчик без преобразования.
- Редактирование и запись комментариев остаются штатными операциями WinBox.
  Проверка сохранения комментариев на реальном RouterOS не выполнялась.
- Неопределённый байт Windows-1251 `0x98`, неверный ввод в строгом режиме
  или строка длиннее 1 МиБ приводят к пустому отображению.

Репозиторий содержит исходники патчера и профиль адресов. Сам WinBox,
его пропатченные экземпляры, резервные архивы и пользовательские данные
в репозиторий и релизы не включаются.

## Сборка из исходников

Нужны macOS, Xcode с выбранным macOS SDK, Python 3.10+ и стандартные инструменты
`xcrun`, `swiftc`, `clang`, `lipo`, `codesign`, `ditto`.
Сторонние Python-пакеты не требуются.

```bash
make build
make test
make verify
```

Эквивалент без Make:

```bash
python3 build.py
python3 tests/test_codec.py
python3 tests/test_bridge.py
python3 SwiftPatcher/build.py
python3 scripts/verify_package.py
```

Результаты находятся в `SwiftPatcher/dist/`:

- `WinBox Comment Patcher.app` — универсальное GUI-приложение;
- `WinBox-Comment-Patcher-<версия>.zip` — готовый архив;
- `SHA256SUMS` — контрольные суммы архива и метаданных;
- `build-info.json` — версия, архитектуры и поддерживаемый профиль WinBox.

Версия патчера задаётся только в файле [`VERSION`](VERSION).
Версия поддерживаемого WinBox и адреса переходов задаются в [`profile.json`](profile.json).
Обновление этого профиля требует отдельного анализа новой сборки WinBox.


## Проверка на установленном WinBox

Дополнительные интеграционные проверки требуют поддерживаемого WinBox на Mac:

```bash
python3 SwiftPatcher/test_in_place.py --source /Applications/WinBox.app
```

Проверка создаёт временные тестовые экземпляры, применяет патч по прежнему пути,
проверяет резервный архив, откат после ошибки и отказ повторного применения.
Установленное исходное приложение остаётся неизменным.

Для отдельного уже обновлённого тестового экземпляра:

```bash
python3 tests/run_native.py --app /path/to/TestWinBox.app --editor --arch arm64
python3 tests/run_native.py --app /path/to/TestWinBox.app --editor --arch x86_64
python3 tests/run_native.py --app /path/to/TestWinBox.app --arch arm64
python3 tests/run_native.py --app /path/to/TestWinBox.app --arch x86_64
```

На Apple Silicon проверка x86_64 требует Rosetta 2. Нативные пробы вызывают
настоящие функции WinBox, проверяют отображаемую UTF-16 строку и неизменность
исходных байтов, затем завершаются до запуска основной программы.
Они не подключаются к RouterOS. Проба редактора дополнительно сравнивает
поле `Name` с исходным обработчиком WinBox, чтобы исключить побочные изменения.
